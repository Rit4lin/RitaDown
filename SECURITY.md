# Política de seguridad

## Versiones compatibles

Solo la versión estable más reciente recibe correcciones de seguridad.

## Informar de una vulnerabilidad

No publiques detalles de una vulnerabilidad en una Issue pública. Abre una Discussion privada de seguridad en GitHub, si está habilitada, o contacta al propietario del repositorio mediante su perfil de GitHub con una descripción, pasos de reproducción e impacto esperado.

Se confirmará la recepción del aviso y se coordinará una corrección antes de divulgar detalles técnicos.

## Despliegue seguro

RitaDown está diseñada para una red de confianza. No contiene autenticación integrada y no debe exponerse directamente a Internet. Utiliza una VPN privada o un proxy inverso con HTTPS y autenticación si necesitas acceso remoto.
